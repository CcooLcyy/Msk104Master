# 短浮点遥调与验收

首版支持一个信息地址的 `C_SE_NC_1` 短浮点直接执行。连接在 STARTDT 确认后才能发送。请求使用连接的 CA、24 位 IOA、有限的 32 位浮点设定值、`COT=6` 和 `QOS=0`。工作台和测试使用同一桌面协议会话。

同一会话最多等待一笔遥调确认。匹配类型、CA、IOA、线上的浮点值及直接执行限定词，忽略测试报文。肯定 `COT=7` 结束等待；若本笔仍是最近一次遥调，随后匹配的 `COT=10` 会更新为终止。否定确认或对应协议错误显示为拒绝。等待确认默认 15 秒，超时后须重连，避免迟到响应被当作下一笔结果。连接中断后保留命令状态与已收集证据。等待与错误均不会自动重发。

工作台显示最近一次命令的本地编号、地址、设定值、发送时间和协议结果。报文列表保留命令收发方向、时间和原始字节。AGC 分配和闭锁遥信由测试用例另行观察。验收覆盖固定报文字节、STARTDT 门槛、肯定确认与终止、否定确认、无关响应、超时和断开。
