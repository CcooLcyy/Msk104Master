# 工作台协议接入

点击连接后，桌面进程在专用线程建立 TCP 连接并发出 STARTDT。工作台分别显示连接中、TCP 已建立但等待 STARTDT 确认、数据传输已启动、断开中和未连接。收到 STARTDT 确认后可发送总召。传输异常后显示错误和已记录的报文，用户可主动重连。断开关闭会话套接字，TCP 建连期间的断开请求由工作线程在建连返回后处理。

总召显示排队或已发送、肯定或否定确认、终止等实际进度。仅匹配当前公共地址、QOI 20 且非测试的总召响应推进状态。等待响应期间禁止重复发起。总召没有事务 ID，同一连接超时重试时，迟到的上一轮响应可能与本轮混淆。需要明确区分两轮证据时，先断开并重新连接再发起。

点值显示来自内核实际收到的遥信和遥测，带时标的遥信也进入 SOE。点表按公共地址、信息地址及点类别更新最新值，报文记录可查看原始字节和相应解析。发送失败单独显示，不计入成功发送。暂停冻结界面的报文和点值，工作线程继续收发。恢复后读取最新快照。清空清除显示数据，保留会话状态和总召进度。新连接清除上一会话的数据。

工作台保留最近 500 条报文、2,000 个点的最新值和 500 条 SOE。协议时标显示原始 CP56Time2a 字节，接收时间显示工作台所在机器的本地时间。

验收使用固定报文和 TCP 回环证据，核对 STARTDT 前后操作权限、总召进度、真实点值及原始报文、异常断开、重连与显示边界。工作台初始渲染不得自动连接或填充点值。验证通过 GitHub Actions 执行。
