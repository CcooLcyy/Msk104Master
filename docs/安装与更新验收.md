# 安装与更新验收

## 范围

交付 Windows x64 NSIS 安装包，支持首次安装、卸载和覆盖升级。更新资产沿用 slaveSim 的 R2 存储桶，使用独立 `msk104master/ci` 前缀和 Tauri 签名清单。主站协议功能不在本次范围内。

## 行为与异常

- 界面提供检查更新、版本说明及下载安装入口，只有检查返回新版本后才允许安装。
- Rust 保存已检查的更新对象；安装使用该对象，不能由界面传入任意下载地址。
- 检查与安装串行执行；网络错误、无候选版本和签名错误均显示中文信息并可重试。
- 检查失败清空旧候选，不能将失败展示为已是最新版本；下载与签名校验失败不得安装。
- Windows 安装会退出当前程序，由安装器升级并重新打开；界面提前告知。
- CI 校验版本、安装器与签名后先上传资产，最后更新 latest.json，公共下载核验成功才算发布成功。

## 验收标准

1. 对应提交的 GitLab CI 通过格式检查、Clippy、单元测试、前端构建和 NSIS 打包，归档安装器与签名。
2. CI 发布独立 R2 清单，清单中的 Windows 资产可下载且摘要与归档一致。
3. 人工安装后可打开中文工作台，应用信息显示当前构建版本；可卸载。
4. 旧安装版本检查到新版本，点击下载安装后可升级；断网、无更新和无候选安装有明确提示。
5. 签名不合法的更新被拒绝；安装和跨版本升级属于人工验收，不能仅凭构建通过宣称完成。
