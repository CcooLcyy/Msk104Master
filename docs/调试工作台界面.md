# 调试工作台界面

## 目标与边界

按用户确认的 ProIEC104Client 分区实现紧凑桌面工作台，沿用 Tauri、React 和现有更新能力。本次仅实现界面，不增加网络连接、协议会话或命令发送，不修改被测 DSP。

## 布局与交互

- 顶部常驻连接、断开、总召、对时、清空显示、暂停显示、自动滚动与导出入口；尚无协议能力的操作禁用并说明原因。
- 左侧常驻运行状态及收发统计，可折叠；未连接时统计为零、最近接收为无数据。
- 中央上部为报文列表，下部为原始报文与解析详情；无真实数据时保持空状态。暂停仅影响显示，不代表停止协议传输。
- 右侧为可折叠通信设置，保留主机、端口、公共地址输入与现有无网络副作用的校验。修改参数立即清除先前校验结果；异步校验期间禁止修改。
- 底部分类页签为遥信、遥测、遥控、遥调、电量、SOE，显示分类列头及诚实空状态。遥控和遥调发送入口保持禁用。
- 中央上下分区可拖动调节，并支持键盘调节；设置及状态侧栏可恢复显示。表格在窄窗口内滚动，默认及最小窗口尺寸下均可访问主要操作。
- 保留版本、更新检查与安装流程；不伪造点值、报文、协议确认或连接成功提示。

## 验收与验证

1. 同一工作台中可见报文、详情、分类点表及会话状态，不再依赖四个互斥业务页面。
2. 六类页签可以切换；侧栏折叠及恢复、显示暂停和自动滚动具有明确界面状态，相关交互记录中文日志。
3. 参数校验仍调用原命令，成功仅表示格式有效；协议操作均不能发送报文。
4. 空表、未实现状态及现有更新面板保留；无隐式网络连接。
5. 对应提交的 GitHub Actions 运行界面结构回归、类型检查、生产构建和既有 Rust/更新测试。本地不构建或测试；真机通信不在本轮验收范围。

## 视觉细节优化

保留原 104 工具的分区框架与当前操作逻辑，按用户确认的字号、配色、间距和边框方向优化：

- 正文、表格与输入采用 13px，辅助信息不小于 12px；标题通过字重和颜色区分，避免大量细小浅灰文字。
- 采用浅灰工作区、白色内容区、深色正文；蓝色用于选中、聚焦与可操作状态。减少渐变和重复的重边框。
- 按钮与输入统一为 32px 高；面板标题、表头、页签保持紧凑且对齐，侧栏采用统一的行距和内边距。
- 自动滚动复选框与文字水平对齐；空表提示在可用空间中居中，避免贴在表头下方。
- 保留六类页签、两侧折叠、分隔栏调节、参数校验、更新与协议操作禁用状态；最小窗口下允许区域内部滚动。
- 纯样式调整复用现有界面结构回归及 CI，不增加绑定 CSS 数值的测试；像素效果与实际桌面交互需在新版本中验收，不能由 SSR 结果替代。

### 对比度与层次增强

- 深蓝顶栏与浅灰工作区分层，顶栏可用操作采用浅色按钮，禁用操作保持灰暗且保留原因提示。
- 面板标题采用蓝灰底、深色文字与蓝色标记，表头采用较浅底色；白色内容区保留，避免大面积深色影响报文阅读。
- 点表选中页签、详情选中按钮及参数校验按钮采用实心蓝底白字；悬停、键盘焦点和禁用状态分别可辨。
- 未连接采用灰色状态块，协议未实现提示采用琥珀色提示条；不通过绿色、闪烁或状态灯暗示正在通信。
- 验收重点：顶栏、标题、表头与内容层次清楚，选中项一眼可辨，辅助文字可读；两侧折叠、窄窗口滚动和更新弹层保持原行为。本轮只改样式，沿用现有 CI 回归，不在本地运行构建与测试。
